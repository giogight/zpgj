# zpgj｜账号内容工作流

一个跨行业的 Agent Skill，把已有账号资料与素材用于策划、定位、选题、口播脚本、开头修改、审稿和素材整理。

完整规范入口：[规范对应清单](skills/zpgj/references/rules-map.md)。初审、根据意见修改、二次复审与定稿交付有各自的规则，不合并为一句“自查”。

当前版本是 **0.2.0**，首个公开测试版。欢迎用真实任务测试，并反馈具体不符合规范的句子或行为。

## 最短用法

安装到支持 Agent Skills 的客户端后，直接发送任务，例如：

> 使用 $zpgj，审核这份口播稿。先给少数有原句依据的问题和改法，暂不重写全文。

> 使用 $zpgj，从这份 IP 访谈转写中出 2 条选题。沿用当前账号目标，素材够就直接出题，不拆视频、不写整稿。

> 使用 $zpgj，只改这条稿的开头，保持正文主线，并给接入正文的下一句。

> 使用 $zpgj，根据上一轮审核意见修改这版稿。先判断意见是否成立，保留原本有效的表达。

> 使用 $zpgj，对修改稿进行二次复审。检查旧问题、新问题、原任务和最佳版本，并复核上一轮意见本身，不自动重写。

> 使用 $zpgj，返回目前推荐的最终稿。没有必须改的问题时保持正文，不制造新版本。

> 使用 $zpgj，分析这条视频的脚本和呈现，提炼用于指定行业的做法，并整理素材卡。

明确要求“分析并成稿”时可以连做；仅要求分析时就交分析与复用素材。

## 方法

- 优先使用录音、访谈、本人原话和已有材料，视频拆解是可选分支。
- 选题先“具体内容＋观看理由＋补充”，再拟标题、评分与筛选。
- 写前区分确定答案、规则下的个人选择和叙事/观点；关键规则与数字先核实。
- 初审给原句、原因、具体改法，允许零问题；明确改稿后才编辑；二次复审检查修复效果和旧意见本身。
- 四段看稿标签供检查，按内容类型展开；保留自然口语与成立的原意。
- 素材区分原行业与目标复用行业，标清原声、字幕、抽帧、初筛和完整分析的范围。
- 行业检索与真实作品搜索、发布后的数据复盘作为可选工作，不改变录音优先的主线。

## 安装

从 GitHub 安装到支持 Agent Skills 的客户端：

```bash
npx -y skills add giogight/zpgj -g --all
```

仅安装到 Codex：

```powershell
npx -y skills add giogight/zpgj --skill zpgj --agent codex --global --copy --yes
```

仓库地址：[giogight/zpgj](https://github.com/giogight/zpgj)。

这个仓库目录包含一个 Skill：`skills/zpgj/`。

使用官方 Skills CLI 安装当前本地目录到 Codex：

```powershell
npx -y skills add . --skill zpgj --agent codex --global --copy --yes
```

安装器来自 [vercel-labs/skills](https://github.com/vercel-labs/skills)。也可把完整 Skill 目录交给其他支持 Agent Skills 的客户端，按其安装说明处理；不要只复制入口文件而遗漏引用资源。

不支持 Skills 的 Agent 可以从 `SKILL.md` 开始读取，并确保能访问其相对引用。

## 运行条件

核心策划、选题、写稿和审稿只需要 Agent 能读取文本及相对引用，无专用软件或其他 Skill 的硬依赖。
视频完整分析需要宿主能够实际读取音画；仅取得字幕或抽帧时会给出范围受限的结果。
涉及当前规则与公开事实时需要可靠查询能力；未取得必要来源时会保留未知项。
归档使用项目指定的位置，标准 Markdown 可由多种笔记或文件工具管理。

## 测试与许可

先用自己的真实任务检查方法是否合用，重点看是否保住账号目标、素材依据和口语表达。
分发内容包括 Skill 规范、项目配置示例和模板；原始聊天、人物素材、私密评测和运行日志不在仓库中。
核心方法已做本地结构检查和真实任务验证。完整视频音画分析与实际发布效果仍需在对应环境验证；公开测试版不承诺效果。
