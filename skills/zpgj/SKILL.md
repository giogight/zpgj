# zpgj｜账号内容工作流

把现有材料变成符合账号目标、能拍能讲、有依据的内容。
先完成用户本次要的交付，不为走完整流程增加访谈、视频研究、审批或新文件。
这是跨行业方法：具体人物、城市、产品、平台约束和表达习惯来自当前项目，不能从示例借来。

## 先恢复当前任务

从用户请求、当前对话和其提供的项目材料取得：

- 当前是哪一个账号、由谁表达，主要为了什么；
- 给谁看，观众正在经历什么；
- 本轮要策划、定位、出题、写稿、改开头、审稿，还是分析视频、整理素材；
- 已有材料、已确认方向、最终数量、允许修改范围和公开边界。

不同账号分别判断。个人曝光、合作探索、精准获客与产品推广不能共用一个未核实的目标。
信息足够就推进。缺口会改变受众、主要结论、账号适配或交付范围时，集中问最少关键问题；初审/复审每轮最多三个，写稿确有多项决定性缺口时最多五个，先做不依赖答案的部分。
不要重复询问已明确的信息。用户说“直接做”时，公开说明必要假设；缺失的事实不能靠假设变成真实经历或产品规则。

只发材料且当前任务明确时沿用该任务；当前任务不明确时，先读材料，再简短确认要哪种处理。
收到脚本不等于收到视频：没有音画和后台数据时，不能声称看过成片、知道真实观众画像或精确划走时间。

## 默认主线与可选分支

新账号可按“策划 → 访谈 → 录音/材料确认定位 → 提取素材 → 选题 → 写稿 → 审核”推进。
已有定位、素材或选题时，从当前阶段进入，省去已经完成的工作。

**优先现有录音和 IP 素材出题。视频是可选分支，不是选题的前置条件。**

- 现有材料足够，直接出题。
- 行业陌生、用户需要表达参考或明确给视频让拆解时，启用视频分支。
- 需要真实作品搜索时使用可选行业研究，检索计划与实际执行分开记录；发布后有数据再按需复盘。
- 没有本人录音但有可靠公开资料，可以做有依据的科普或解答方向；不能据此补造本人故事。
- 用户只说分析视频，交付分析和复用素材；明确要求分析并成稿时，按现有证据完成选题、成稿和内部自审。
- 只要选题就不交整稿，只要审稿就不默认改稿；只改开头不擅自改掉正文主线。

## 共同方法

### 1. 素材与证据先分层

区分公开事实、作者自述、已确认观点、助手推断、模拟情境和未知信息。
保留来源文件、原句、说话人和可支持的定位/时间范围；概括不伪装成引语。
原作者的经历、资质、客户和结果不能转成我们的事实。
需要完整模拟人物故事时，先取得用户明确授权，交付时标为创作设定；演示算例写清假设。
用户确认可以表达一个观点，不等于确认某件事真实发生。

### 2. 选题先公式，再标题与筛选

每条先确定 **具体内容＋观看理由＋补充**，再拟一遍能懂的标题。
观看理由具体到某类观众的疑问、处境或期待；补充服务于讲清内容，不靠编细节制造反差。
按要求数量交付，区分候选数与最终数。评分使用五项各 0–2 分的内部比较，不是流量概率。
叙事框架讲事件推进，解答框架讲依据、原因、判断或动作，不把所有题都改成故事。

### 3. 写前先知道能讲到哪里

先判断本题是否有确定答案、是否有明确规则但选择因人而异，或属于叙事/观点。
有规则与数字时先核实适用来源、条件和口径，再核算与创作；有资料不自动代表这个题值得拍。
核实能够改变核心结论的金融、医疗、法律、政策和平台规则，优先可信一手来源并标明适用范围。
用户提供的业务约束照做，不能冒充已经核实的全平台政策。
无法核实的项目明确留为未知，收窄可交付部分；不为成稿编出统一费率、审批结果或专业身份。

### 4. 讲给人听，保留内容实质

先抓眼前的事，再按说话人的自然语序表达。口语不是把书面句子拆短行。
内部核算可以充分，正文只讲观众需要的结果、依据与决定结论的条件。
四段“痛点、冲突、框架、共鸣”默认作为看稿标签，不是口播台词；按类型展开，用户指定其他结构时优先。
不为凑标签、审核维度或通用模板增加没有作用的内容，不把故事改成教程，不把解答改成只有态度。

### 5. 初审、修改、二次复审与定稿分开

审核先对照标题/开头承诺和正文实际交付，再找实质、证据、逻辑与听懂障碍。
每个重要问题给出原句或位置、具体原因、修改方向。优先根本问题，允许零新增问题。
事实核验通过不等于内容质量通过；缺案例、长句或不同审美也不自动构成错误。
收到明确改稿要求后读取修改规范，分别判断问题是否成立、建议改法是否适合，再按问题大小编辑。
保留成立的立场、人物因果、有效细节与表达。局部改后连读前后，检查衔接、重复与结论一致性。
涉及已确认核心方向的变更才确认；常规编辑不增加一轮“可以开始吗”的审批。

复审不是只查有没有照做：同时检查旧问题是否解决、新问题、原任务是否保留、相对最佳版是否改善，并复核上一轮意见本身。
作者用其他方法修复有效就认可；旧意见过度、无依据或导致偏题就修正或撤回，不维护错误判断。
当前与最佳版相同不能假称新改善。问题解决可保留定稿；需要最终版时原样返回推荐稿，不制造新版本。

## 工具与交付

使用当前宿主实际可用、已授权的工具。Chrome、字幕软件、笔记软件和其他 Skill 都不是运行硬依赖。
只有字幕或抽帧时说明实际范围；不能把机器初筛写成完整听校或连续看完全片。
打开链接不意味着点赞、关注、评论、私信或发布授权。
保存位置沿用用户或项目指定目录；没有位置时先交可审阅成果，必要时询问目录，不擅自写入个人资料库。
文件写后重读并核对来源链接、数量、金额与修改范围；本地写入、外部上传与公开发布分别验收。

默认用简体中文，先结论，再给必要依据与可操作结果。用户明确其他语言时遵从。
交付形式按当前任务变化，不输出每一阶段的大报告，不把核验备注和审核过程塞进口播。
视频读取、素材登记、素材初筛、完整分析与用户认可分别记录状态，不混称“全部完成”。

当前交付完成就结束。剩余关键缺口、未取得的音画或未验证的效果如实说明，不制造额外工作。
