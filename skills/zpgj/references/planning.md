# 策划、访谈与定位

用于启动账号策划、整理访谈问题、依据录音确认或修订定位。
已有清楚的账号目标和可用素材时，直接进入当前任务，不重新做完整访谈。

## 1. 先确定当前要解决什么

从当前对话和已有资料提取已知信息；必要时使用 [账号简报模板](../assets/account-brief.md)。
一个账号一份简报，多个账号分别判断目标、受众与素材适用性。

| 情况 | 当前动作 | 本轮交付 |
|---|---|---|
| 只有行业和账号想法 | 梳理目标、受众与可用人物材料 | 初步策划与关键访谈问题 |
| 已有访谈录音或转写 | 提取原话、经历、判断与行为 | 证据表、定位建议与可用素材 |
| 已确认定位，要求出题 | 读取已有材料直接构思 | 按选题规则交付，不重做策划 |
| 后来补充了录音 | 对照原结论检查变化 | 修订涉及的判断与选题 |
| 没有录音，要求科普方向 | 使用可靠公开资料梳理问题 | 有来源的科普方向与待核项 |

只有缺失信息会改变判断时才提问，集中问影响最大的几项：

- 本轮主要为了曝光、精准咨询、成交、建立信任，还是探索合作？优先哪一个？
- 希望谁看，他在什么情境下会关心这类内容？
- 哪些材料能公开，哪些身份、经历或业务信息不能使用？

用户已说过的目标、受众、数量和限制不要重复问。
产品尚未确定时，可以先做曝光或合作探索；不为完成表格虚构商业模式。
缺少某个故事结局时，只暂缓该故事，不停止其他有依据的方向。

## 2. 写一份可用于判断的初步策划

先推荐一个方向，解释它怎样服务账号目标，再保留需要用户选择的分歧。
策划应说明以下内容，不把建议写成用户已确认的事实：

- **账号目标**：当前优先结果、可观察的验证信号；没有数据时不编指标。
- **目标受众**：具体人群、生活或工作情境、最想解决的事。
- **内容承诺**：观众看这个账号，能够持续获得什么。
- **人物基础**：能从原话或经历支撑的身份、性格、做事方式与表达习惯。
- **商业方向**：想与谁合作、提供什么价值、通过什么现有路径承接。
- **制作条件**：真人口播或其他形式、现有拍摄条件、能承担的工作量。
- **内容边界**：不能编造、不能公开、不能使用的表达或引导方式。

“人物有意思”和“商业上可能有用”分别论证，不能互相替代。
用户重曝光时，题材可以拓宽，但仍要与真实人物和目标受众有关。
用户重精准咨询或成交时，重点检查受众与需求是否匹配；不套用曝光账号的筛选理由。

## 3. 把访谈问到具体场景

只挑对本轮定位有用的问题。已有答案的部分直接整理，不让用户重复讲。
问题围绕真实经历和选择展开，不用“你是不是很负责”之类的问题诱导人设。

| 要了解什么 | 可直接使用的问法 |
|---|---|
| 当前目标 | 这个账号做起来后，你最希望出现什么具体变化？ |
| 受众情境 | 你想吸引的人，一般在什么事情上会来找你？ |
| 真实经历 | 最近一次印象深的事情是什么？从开始到结束怎么发生的？ |
| 人物选择 | 当时还有哪些办法？你为什么选这个？付出了什么？ |
| 行为证据 | 你具体说了什么、做了什么？对方怎样回应？ |
| 判断来源 | 哪次经历让你形成了这个看法？有没有相反的情况？ |
| 商业能力 | 别人实际愿意为什么事情付费或合作？你已经做到哪一步？ |
| 公开边界 | 这段事能公开到什么程度？哪些人物、数字和细节要隐去？ |

遇到有潜力的经历，追问时间、起因、困难、选择、变化和实际结果。
遇到只有态度的回答，追问“有没有一次具体的事”，不替人物补故事。
没有发生过的经历可以记录为想法，不能作为本人经历使用。

## 4. 将录音转成可追溯材料

先判断拿到的是原始音频、机器转写、人工转写还是整理纪要，并记录材料状态。
只读过转写时，不能声称已经听录音；不清楚的说话人、词语和数字标为待核。
原始材料保留原样；清理口头重复、纠正错字或补解释时，与原句区分。

| 字段 | 记录要求 |
|---|---|
| 素材编号 | 在当前项目中能唯一找到这条材料 |
| 来源位置 | 文件名、段落或实际时间戳；没有时间戳就写段落，不编时间 |
| 原句 | 保留说话人的表达，不把概括放进引号 |
| 材料类型 | 经历、观点、行为、背景、业务信息或表达习惯 |
| 已知经过 | 只写录音提供的事实，区分本人说法与另行核实结果 |
| 缺失信息 | 缺起因、数字、结果、公开许可等，逐项注明 |
| 可用方向 | 哪个受众问题、人物判断或具体选题可由此支撑 |

提取时优先找具体选择、代价、误解、变化、动作和人物原话。
同一句原话可以支撑多个角度，但每个角度需要不同的内容或观看收获。
“本人在录音里这样说”只证明有这段说法，不自动证明事件全部真实。

## 5. 分开确认人物定位与商业定位

每个关键结论标一种状态，并附依据：

- **已确认**：用户明确确认，或材料确有这段表述；说明确认的是哪一层事实。
- **助手推断**：由多条材料推导的理解，写出推断链和仍可能存在的其他解释。
- **待核实**：缺材料、说法冲突、外部事实未核对，暂不当成确定结论。

人物定位回答：他是谁、怎样做选择、有哪些可持续展示的特点。
商业定位回答：为谁提供什么价值、已有能力与合作路径是什么、哪些仍在探索。
学习某个专业不等于具有执业身份；愿景不等于资质，观点不等于服务成果。
不要根据少量材料给人物贴固定性格标签，也不要借用其他作者的经历塑造他。

新增录音与原定位冲突时，列出“原判断—新依据—修订建议”，只改受影响部分。
用户要求另存或保留旧版时新建版本；保留原始录音、转写和来源记录。

## 6. 定位后选择素材路径

**默认路径：现有录音或 IP 素材 → 提取可用内容 → 出题、评分与筛选。**
素材已经足够支撑用户要的数量，就直接出题。
不足时说明缺的是故事经过、事实依据还是表达参考，再补对应材料。
没有录音也可以依据可靠公开资料做科普内容，不强制等待录音。
公开案例仍归属于原人物；可以结合 IP 已有观点评论，不改写成本人或客户亲历。

视频拆解是可选分支：用户需要视频参考，或行业陌生且选择通过视频补充认知时使用。
从视频借鉴内容组织、表达方法或行业问题，不能借走作者身份、经历和未经核实的结论。
可复用内容回到同一套选题公式；不因为拆过视频就强行安排拍摄形式。
法律、医疗、金融、平台规则等具体判断另行核实适用条件和当前来源。

进入选题时读取 [选题构思与筛选](topics.md)，只携带本轮需要的定位和素材。
