# 素材库归档与索引

当前任务要求保存或归档时使用本文件。素材库服务于真实材料出题和后续复用；建库、取得原片、登记或机器初筛不等于分析完成。

## 保存位置与结构

优先使用用户或项目指定的目录。未指定正式归档目的地时可先交素材卡和本地可审阅成果；需要正式归档才确认位置。不要擅自写入个人盘符、已有知识库或外部平台，也不要将“卡已生成”说成“已归档”。

视频实行**一条原视频一个目录**，多个目标行业的复用卡共同引用原片，不复制成多个原片目录。建议结构，可按已有项目约定调整：

```text
material-library/
  index.md
  source-industries/<原行业>.md
  reuse-industries/<目标行业>.md
  videos/<素材ID-作者-短标题>/
    material.md              # 来源登记、读取范围与各项状态
    original.<实际格式>      # 仅在确实取得且允许保存时存在
    transcript.md            # 标明机器稿/部分核准/完整核准
    analysis.md              # 脚本与呈现分析及证据范围
    reuse/<目标行业>.md      # 目标复用卡，可有多张
    derived/                 # 本片实际产生且要求保存的练习稿/延伸成果
  comparisons/               # 多片合并对照及其实际衍生成果
```

保留原始来源链接；不能保存原片时在登记中写明，不建立假原片或标成已取得。IP 录音可沿用来源、范围和状态规则，保存实际音频格式；不要为进入主工作流而要求补视频。
由某片实际产生的练习稿或延伸成果与该片同目录记录，并链接来源；只分析任务不为填目录自动生成练习稿。
多片合并对照及其示范稿单独保存，写清每一条来源各贡献什么；各单片反向链接合并成果，合并成果链接单片材料。一份成果多处索引，共用原件，不重复复制或把多个作者故事拼成一个真实案例。

## 登记与去重

使用稳定素材 ID：优先平台作品 ID，缺失时用项目内唯一 ID，并记录可核对的作者、标题、来源及日期。先查已有 ID、作品链接和文件；短链接不同不当然是新视频。确认同一原片后补充现有记录和目标复用卡，不重复建档。不同版本或剪辑记录版本关系，不能混用时间点与证据。

登记最少包含：素材 ID、作者、标题、来源链接、原行业、实际文件与读取范围、各项状态、分析链接、目标复用卡链接。未知信息写未知，目标行业未指定写待指定；不靠目录名推断所有字段。

状态分开维护，不用一个“完成”覆盖全部：

| 状态项 | 可用标记示例 |
|---|---|
| 来源/原件 | 仅线索、已取得原件、来源待核对 |
| 声音核对 | 未核对、部分核对（具体范围）、全片核对 |
| 画面核对 | 未取得、抽帧辅助（时间/范围）、部分连续观看、全片连续观看 |
| 转写 | 无、机器初稿未核准、部分核准、完整核准 |
| 内容分析 | 未做、初筛、范围受限分析、全片分析完成 |
| 目标复用 | 未做、条件建议、已适配（注明目标） |
| 归档 | 待保存、已写入并检查链接 |

“全片分析完成”须满足本次分析所需音画实际核对；只有机器转写和抽帧时应标初筛或范围受限。复用卡注明分析时点与证据范围，旧卡不能因新原件入库自动升级状态。源登记是当前读取与转写状态的查阅入口。

## 两类行业索引与双向引用

- **原行业索引**回答“这条原视频来自哪个行业”，链接素材登记和原片分析。
- **目标复用行业索引**回答“我们要借到哪个行业、能借什么”，链接对应目标复用卡；不能只归原行业而漏掉目标行业。
- 总索引同时显示素材 ID、原行业、已分析的目标行业、状态与目录入口。目标尚未确定时保留待指定，不假建目标适配。
- 每个索引链接具体登记或卡片；登记和卡片反向链接相关索引与彼此。同一素材同一目标只保留一个主卡，修订在原卡记录；多个目标可各自建卡并共用原件。

使用标准 Markdown 相对链接。总索引到素材登记的路径形如 `videos/素材目录/material.md`；行业索引到目标复用卡的路径形如 `../videos/素材目录/reuse/目标行业.md`。实际生成链接时换成已存在的目录和文件，按层级计算反向链接，不硬编码绝对路径。Obsidian 可选，不要求专用双链语法。

## 写后检查与汇报

可从 [目标复用卡模板](../assets/material-card.md) 建卡。只填实际取得和核对的信息；原作者事实、创作示意和目标账号事实分开。

写后重读本次文件，检查目录、来源、状态、索引及所有相对链接能否回到实际文件，确认没有重复原片或错误行业归类。批量成果可附一份可独立阅读的汇总，但不能代替单条来源与范围记录。

汇报具体位置和本轮完成范围，例如“6 条原片已登记，其中 3 条做了范围受限初筛，尚未完成原声逐字核对”。只有真正写入指定库并检查后才称已归档；不得把线索、登记、初筛、全片拆解或成稿混称完成。
